## 🌿 About The Project

**TeaHouse** is a modern responsive landing page designed for a tea-focused business.

The website combines a warm tea-inspired visual design with responsive layouts and interactive JavaScript features to provide a smooth experience across desktop, tablet, and mobile devices.

The project was created as a **frontend development project** to demonstrate practical skills in:

- HTML structure
- CSS styling
- Responsive web design
- JavaScript DOM manipulation
- Interactive UI components
- Local Storage
- Mobile-first user experience

---

## ✨ Key Highlights

🎥 **Video Hero Section**  
A tea video is used in the Home section to create a more engaging first impression.

🌙 **Light & Dark Mode**  
Users can switch between Light Mode and Dark Mode.

💾 **Theme Persistence**  
The selected theme is saved using `localStorage`, so the preference remains after refreshing the page.

📱 **Fully Responsive**  
The layout adapts to desktop, laptop, tablet, and mobile screen sizes.

📩 **Interactive Contact Form**  
Users can submit their details and receive a confirmation message.

☰ **Mobile Navigation**  
A responsive navigation menu is available for smaller screens.

🍵 **Tea-Focused UI**  
Warm colors, clean layouts, tea imagery, and structured sections create a consistent tea-house experience.

## 🖥️ Website Sections

### 🏠 1. Home

The Home section introduces the TeaHouse brand with:

- Main heading
- Tea-focused description
- Call-to-action buttons
- Tea video

The hero video automatically plays, remains muted, and loops continuously.

---

### 🍃 2. About

The About section introduces the TeaHouse concept and provides information about the brand and its tea experience.

---

### ☕ 3. Tea Menu

The Menu section showcases different tea varieties in an organized and visually appealing layout.

The section is designed to make the tea options easy to explore.

---

### ⭐ 4. Testimonials

The Testimonials section displays customer feedback to create trust and give visitors an idea of the customer experience.

---

### 🖼️ 5. Gallery

The Gallery section provides a visual showcase related to TeaHouse and its tea products.

---

### 📍 6. Contact

The Contact section allows visitors to get in touch with TeaHouse.

It includes:

- Address
- Email
- Phone number
- Opening hours
- Website information
- Contact form

The contact form provides a confirmation message after submission and automatically resets the form.

> **Note:** The current contact form is a frontend interaction and does not send data to a backend or email service.
